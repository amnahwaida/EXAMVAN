# PyInstaller --version-file untuk EXAMVAN.exe
#
# Isi metadata ini yang muncul di:
#   Windows Explorer -> properties EXAMVAN.exe -> tab "Details"
#   Add/Remove Programs (kalau lewat EXAMVAN-Setup.exe)
#
# Dipakai build-exe.bat, build-exe.ps1, dan CI. SEMUA field versi di bawah
# (FixedFileInfo filevers/prodvers DAN StringStruct FileVersion/
# ProductVersion) di-stamp oleh `build_info.py stamp` sebelum PyInstaller
# dipanggil.
#
# Default di sini sengaja SAMA dengan APP_VERSION, bukan 1.0.0: file ini
# pernah tidak pernah di-stamp untuk FixedFileInfo, jadi setiap exe punya
# biner 1.0.0.0 sementara ProductVersion 2.5.0. Default yang salah membuat
# build yang melewatkan stamping tetap berlabel versi yang tidak pernah
# ada. Satu-satunya tempat yang boleh diubah: baris APP_VERSION di
# desktop/examvan/__init__.py.
#
# Format: sintaks Python VERSIONINFO resource, bukan JSON.
# 0421 = Indonesian (LCID 1057), 04B0 = Unicode codepage.
